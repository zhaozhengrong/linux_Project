# 环境搭建
## 1.安装opencv库
```base
  sudo apt install libopencv-dev
```

## 2.下载NCNN源码
```base
  git clone https://github.com/Tencent/ncnn.git
```
创建编译目录
```base
  mkdir build
  cd build
```
进入build 
1.执行`cmake .` 这里只是生成编译规则，还没有真正编译
```base
  cmake ..
```
如果直接执行`cmake ..` ncnn 默认判断
当前系统 = x86 
当前编译器 = gcc/g++
目标 = x86
最后会编译为 Target arch: x86 32bit

2.对于单片机或者t113来说要使用
```
cmake .. \
-DCMAKE_TOOLCHAIN_FILE=../arm-linux-toolchain.cmake \
-DNCNN_BUILD_EXAMPLES=OFF \
-DNCNN_BUILD_TOOLS=OFF \
-DNCNN_VULKAN=OFF \
-DNCNN_OPENMP=OFF
```
生成T113这样可以使用的文件

然后开始编译 将`/src` 路径下的源码编译为静态库 `.a`
```base
  make -j$(nproc)
```

此时编译完之后 项目通常需要这三部分：
1. 源码头文件（src/*.h）这些是 NCNN 作者写的头文件。
2. 编译时生成的头文件（build/src/*.h）这里面的文件不是手写的，而是 CMake 在编译过程中自动生成的。
3. 静态库（build/src/libncnn.a）

这个是自己的目录
include/：放 src/*.h 和 build/src/*.h

lib/：放 libncnn.a
